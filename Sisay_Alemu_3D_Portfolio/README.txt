What's included
- index.html: portfolio website
- style.css: responsive styling, 3D portrait effects, map layout

How to open
1. Extract this ZIP file.
2. Open index.html in Chrome, Edge, or Firefox.
3. An internet connection is needed for Bootstrap/Bootstrap Icons/Google Fonts and the embedded OpenStreetMap.
